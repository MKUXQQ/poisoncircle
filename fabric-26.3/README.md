# 毒圈 · Minecraft 26.3 Fabric

Minecraft 26.3 Fabric 版本的构建与功能补充说明。玩家安装、完整指令和开局流程请先阅读[项目主页](https://github.com/MKUXQQ/poisoncircle)。

当前公开包：[1.0.1+26.3 / V7 测试版](https://github.com/MKUXQQ/poisoncircle/releases/tag/fabric-26.3-v1.0.1-v7)。

## 运行要求

- Minecraft **26.3**
- Fabric Loader **0.20.1 或更新版**
- Fabric API **0.165.0+26.3**
- Java **25 或更新版**

成品：`build/libs/poisoncircle-fabric-1.0.1+26.3.jar`。放进对应实例的 `mods`，然后重新启动游戏。多人游戏需要服务器与客户端都安装此模组，客户端才能显示毒墙、探测器界面和受击效果。

## 功能与移植范围

支持五阶段平滑缩圈、移动圆心、地形筛选、圈外直接扣血、各圈计时与指令、个人探测器、可放置扫描台、大厅保护范围、连续红色光幕、状态 HUD、受击闪红和镜头抖动。光幕使用单层双面半透明发光管线及平滑纵向条纹，没有方格或孔洞；保留视距、视锥及高度分段裁剪。地图圆环按地形缩放计算，并在小地图边界内裁剪。选圈地形筛选仅访问已加载区块，避免同步生成区块。创造与旁观模式免疫伤害。服务器与客户端入口分离，可用于 Fabric 专用服务器。

支持可选 Xaero 小地图/世界地图覆盖：当前圈红色、下一圈白色、个人探测揭示圈青蓝色。按 Minecraft 26.3 的 Xaero 世界地图 1.47.2、小地图 26.6.2 接口构建；可分别安装任意一个地图模组，未安装时不加载对应桥接。世界地图切换到其他维度时不会误画当前维度的圈。个人探测结果只对收到服务器揭示数据的玩家显示。

Xaero 地图为可选依赖；使用小地图覆盖需安装对应 26.3 的 Xaero 小地图，使用世界地图覆盖需安装对应世界地图及其前置。

## 使用

创造模式的「毒圈 · 控制中心」分类包含**毒圈控制器**、**毒圈探测器**、**安全区扫描台**、**大厅范围控制器**、**空降管理器**与**空降设置器**。右键控制器打开管理面板，面板采用米黄色底色与棕色边框。运行页可将当前位置设为中心并启动/停止毒圈，不提供 XYZ 坐标输入或领取探测器按钮，阶段页可设置各圈时间和命令，伤害页可设置扣血。停止操作需要再次点击确认。面板操作仍由服务器检查管理员权限等级 2，结果显示在聊天栏。

探测器保持独立用途，不会打开控制台。也可通过 `/give @s poisoncircle:poison_circle_controller` 获取控制器。原 `/poisoncircle status` 指令已删除，当前运行信息在控制台顶部与 HUD 显示。

管理员权限等级 2，可直接在游戏中执行：

```mcfunction
/poisoncircle center
/poisoncircle start 500 0
/poisoncircle detector
```

`center` 使用当前位置，也可传入 `<x> <y> <z>`。右键探测器直接揭示下下个安全区，不打开界面；该圈以青色显示在 Xaero 地图上，并给出中心坐标与半径。第五圈不允许探测；有可揭示的圈时消耗探测器（创造模式除外），没有可探测圈时不消耗。

其他指令：

```mcfunction
/poisoncircle time <圈数1到5> <等待秒数> <缩圈秒数>
/poisoncircle damage <基础伤害> [每圈增加伤害]
/poisoncircle command <圈数1到5> <要执行的指令>
/poisoncircle stop
```

首次默认启动半径为 500，最终半径固定为 0；旧存档保存的非零终圈半径也会归零。控制台终圈字段只读，无参数 `start` 使用已保存的初始半径。伤害可在启动前设置，启动会继承保存值。计时、命令、伤害、半径及各维度中心按存档路径隔离保存到 `config/poisoncircle/<存档标识>.json`，下次进入同一存档自动读取；移动存档路径会使用独立配置。控制器输入另外保存在 `config/poisoncircle-controller.properties`，各阶段分别记忆，输入值仍须点击应用才会提交服务器。

开局记录参赛玩家；全部参赛者死亡后静默停止毒圈、全域伤害和地图覆盖，不发送停圈聊天提示。死亡后快速重生仍算本局淘汰，未确认死亡的离线玩家不会触发误停；切换创造/旁观也不冒充死亡。也可手动执行 `stop`。探测器青圈在目标圈成为当前圈时自动清除。

连续光幕纹理从空白重绘为 128×128，更鲜明的红色底色配稀疏的红橙分叉电离通道，alpha 48–102，双轴无缝，不绘制格栅、点阵或密集条纹。控制器与探测器分别使用 9 个立体组件及独立 32×32 图集，第一人称翻转正面并缩小。新增扫描台及大厅物品在 Blockbench 制作，可编辑工程保存在 `artifacts/blockbench/`。未进行实际 FPS 对照测量。

放置安全区扫描台后，面向扫描台持续按住右键 5 秒即可揭示下下圈（不包含第五圈），不消耗探测器。服务器选择扫描台邻接一格的安全站位，有地面且可站立时才传送玩家开始操作。扫描自动切换第三人称并锁定移动和瞄准，其他玩家也能看到双手操作动作；进度条使用服务器同步的实际计时。完成或取消立即恢复原视角和控制，继续按住不会再次开始，松开后才能重新扫描。松开、死亡、切换维度或打开界面会取消。扫描次数不限，提示只使用声音，不发送聊天消息。低 TPS 时实际等待可能长于 5 秒。毒圈扣血先同步真实生命值，生命值降至零后进入死亡流程，避免正生命值死亡导致无法正常重生；重生后仍视为本局淘汰。直接扣血不经过护甲和图腾减免。

右键大厅范围控制器打开米黄棕边 UI，以当前位置及输入半径设置同维度全高度的圆柱保护区。也可执行 `/poisoncircle lobby set <半径>`、`/poisoncircle lobby center <x> <y> <z> <半径>`、`/poisoncircle lobby disable`、`/poisoncircle lobby status`。大厅设置随存档持久化。开局位于大厅或比赛中退回大厅的玩家退出本局统计，本局不重新加入并免毒；死亡后复活的淘汰玩家同样免毒。下一次开局重新记录参赛者。

## 空降模式（V7 测试版）

管理员可获取两个独立道具：

```mcfunction
/give @s poisoncircle:airborne_manager
/give @s poisoncircle:airborne_setter
/poisoncircle start airborne
```

管理器首页仅有：开始、强制结束、点位管理、单人、多人、飞行。单人/多人共用同一份点位分组，点击分组立即选中并更新当前组粒子；点击“选择此模式”只改变单人/多人模式，不重置所选分组。多人模式随机两人组队，奇数最后一人独乘。新存档不生成默认组；设置器普通右键地面添加自动地形高度点位，普通左键删除当前组该处点位，潜行左键打开点位列表（只读坐标、改名、删除、管理员本人传送），潜行右键保存为数字命名分组，然后自动切换到空白草稿，普通右键可立即设置下一组；不会预建空组。重复回调、双手或长按不再重复建组；再次设置相同点位内容时复用已有组并回到空白草稿，原组点位仍保留。如选中旧组时另有不同的未保存草稿，则拒绝覆盖并提示先保存草稿。设置器在管理员背包中即可显示当前组/工作点位粒子（同维度 128 格内），不必手持；设置反馈仅发给管理员。飞行高度默认 200 格，接受任意有限正数，不设产品上限；开局仍校验航线地形及游戏坐标安全范围。速度 0.2–2 格/tick。配置原子保存到存档的 `poisoncircle/airborne.json`，损坏文件不会静默覆盖；旧非空默认组保留点位并去掉默认名称。最多 8 组、每组 8 点、每局 32 名生存/冒险玩家。

开局锁定名单及配置，倒数 5 秒后登机，玩家位于真实座椅上并面朝机尾就坐。飞机从目标点水平前方 20 格、巡航高度上方 80 格起飞，逐步下降至配置高度，登机至少 5 秒后接近并停在目标上空。随后由服务端自动打开机尾货舱坡道（约 1.5 秒）、播放起身（约 0.6 秒）、离座并沿双线中央通道走向机尾（约 1.2 秒）、走下坡道并从尾部离机（约 0.9 秒）；座位距尾门约 5 格，整段开门至离机约 4.2 秒，可靠解除乘坐后进入可操控滑翔；所有阶段同步真实三维脚点，不再从机身侧面离开。整个离机过程无需按键或客户端确认，也不再要求玩家自行找出口。异常接近超时有自动离机兜底。离机保留当时空中位置，不传送到地面；飞机随后继续前飞并在无人后清理。队友使用原版计分板队伍，停止后恢复原队伍。滑翔沿用原版鞘翅动量与俯仰换升力规律，W/S 调整推进/制动、A/D 横移，鼠标调整方向与俯仰；不装备或绘制鞘翅。距下方地形约 50 格时切换并腿着陆姿态，近地减速，由服务器碰撞判断落地，不生成降落伞或传送到地面。登机可能跨维度传送，手动中止只将尚在空中的玩家送回开局位置。

空降期间免毒圈伤害，落地后恢复原毒圈规则。毒圈由原控制器另行启动，不替换已锁定名单；自动缩圈/下圈刷新不再刷聊天，缩圈前 10 秒在屏幕上方显示“准备缩圈”约 3 秒。飞机使用真实桌面 Blockbench 第七版 Goblin 风格科幻空降艇（依据 Apex 复活运输艇及 Titanfall 同型艇参考，非官方原模型）：302 方块、单张 512 贴图，整体约长 29.92、宽 18.16、高 8.65 格。新外形包括楔形装甲机头、分段深色座舱、双侧后伸推进舱、八边机械喷口、腹部升力出口和双尾支架；四张真实坐垫/靠背/扶手座椅靠近尾门，舱内有肋梁、管线、灯具和近身设备。机尾货舱门绕底部 X 轴铰链整体打开至 -100°形成坡道，座位和三维离舱路线均与新模型锚点对应。见 `artifacts/airborne-plane-v7/` 的可编辑工程、原生开关门关键帧、审计、双线通行包络采样与开门/关门视图；第五、六版保留在独立目录。舱内坐姿按真实坐垫高度对齐，并在离座时混合起身；披风修复其背部局部旋转而非隐藏，保留原版普通玩家与装备可见性规则。空降 HUD 只显示“空降准备【倒计时】”和“即将登机”。服务端保护、零输入自动离机时间线、共用分组迁移与去重、粒子边界、滑翔、持久化与 UI 有自动化检查；实际多人操控、披风视觉和帧率仍需游戏内验证。当前版本已在 GitHub 的 `port/fabric-26.3` 分支公开，成品见 V7 测试版发布页。

运输艇音效使用三个独立事件 `airborne_engine`、`airborne_door`、`airborne_exit`，分别对应空间定位引擎循环、开门瞬间和本地玩家实际离机；移除飞机、断线及资源重载会清理循环。当前三段 Ogg 是明确标注的临时原创科幻声音，并非 Apex 原声音频。已从 B 站正常下载纯净音效合集、进毒圈异常录像及飞船内部实机参考；合集目录属于武器/治疗/技能，飞船片段混有解说和场景剪辑，尚未确认可直接安装的运输艇独立原声。毒圈 `circle_warning`、`circle_closing`、`circle_damage` 已接入服务端同步驱动的提醒、缩圈边沿及每秒最多一次受毒反馈；缺少对应原声文件时静默，不以其他声音冒充。`artifacts/airborne-audio/audio-manifest.json` 保留运输艇临时素材状态和文件校验值，`artifacts/airborne-audio/references/` 保留 B 站参考及识别记录；尚未完成原声替换和人工听音验证。

## 本地构建

设置 `JAVA_HOME` 为 JDK 25，在本目录执行：

```bat
gradlew.bat build
```

使用 Gradle 9.8.2、Fabric Loom 1.19.3，首次构建需要下载依赖。测试报告在 `build/reports/tests/test/index.html`。

编译 Xaero 可选桥接前，将对应 Fabric 26.3 的 `xaeroworldmap-fabric-26.3-1.47.2.jar`、`xaerominimap-fabric-26.3-26.6.2.jar` 放进本目录 `compile-libs/`，再从世界地图 jar 的 `META-INF/jars/` 提取 `xaerolib-fabric-26.3-1.8.5.jar` 放进同一目录。官方发布页：[世界地图](https://modrinth.com/mod/xaeros-world-map)、[小地图](https://modrinth.com/mod/xaeros-minimap)。这些第三方 jar 仅用于编译，不打包进毒圈模组，也不纳入源码版本控制。
