# 毒圈 · Minecraft 26.3 Fabric

为 Minecraft 大逃杀、终极对决和自定义对抗地图提供的毒圈与空降模组。支持五阶段移动缩圈、红色能量光幕、个人安全区探测、可放置扫描台、大厅保护区，以及带运输艇、自动离机和可操控滑翔的空降开局。

**本页仅介绍 Minecraft 26.3 Fabric 版本。** 当前公开版本为 **1.0.1+26.3 / V7 测试版**，作者：**MKUXQQ**。

[下载 V7 测试版](https://github.com/MKUXQQ/poisoncircle/releases/tag/fabric-26.3-v1.0.1-v7) · [直接下载模组 JAR](https://github.com/MKUXQQ/poisoncircle/releases/download/fabric-26.3-v1.0.1-v7/poisoncircle-fabric-1.0.1%2B26.3.jar) · [26.3 源码与构建说明](https://github.com/MKUXQQ/poisoncircle/tree/port/fabric-26.3/fabric-26.3)

## 安装要求

| 组件 | 要求 |
| --- | --- |
| Minecraft | **26.3** |
| 模组加载器 | **Fabric Loader 0.20.1 或更新版** |
| 前置模组 | **适用于 26.3 的 Fabric API 0.165.0+26.3 或兼容更新版** |
| Java | **25 或更新版** |
| 安装位置 | 单人安装到客户端；联机时服务器与各客户端均需安装 |

1. 创建 Minecraft 26.3 的 Fabric 实例，使用 Java 25 或更新版运行。
2. 下载上方发布页中的模组 JAR，并准备对应 26.3 的 Fabric API。
3. 将两个 JAR 放入该游戏实例的 `mods` 目录；专用服务器也需安装相同版本的模组和前置。
4. 重新启动游戏或服务器。管理员可从创造模式的「毒圈 · 控制中心」分类领取道具。

请使用成品模组 JAR，不要将源码压缩包或 `-sources.jar` 放进 `mods`。此安装说明仅适用于上表中的版本组合。Xaero 地图属于可选增强，不是启动前置。

## 主要功能

- **五阶段缩圈**：圆心与半径平滑变化；第一圈使用管理员设定的中心，后续安全区完整位于上一圈内。后续选圈会筛选地形，且只读取已加载区块，避免同步生成新区块。
- **终圈收束**：最终半径固定为 **0**，旧配置中的非零终圈半径也会归零。每阶段可独立设置等待时间、缩圈时间和执行指令。
- **圈外扣血**：直接扣除生命值，不经过护甲和图腾减免；支持基础伤害及逐圈增量，并显示受击闪红与镜头抖动。创造与旁观模式免疫毒圈伤害。
- **光幕与 HUD**：连续半透明红色能量墙实时跟随安全区；自动缩圈与下圈刷新不刷聊天，缩圈前 10 秒在屏幕上方显示「准备缩圈」约 3 秒。
- **参赛与淘汰**：开局记录参赛者，死亡后重生仍算本局淘汰；全部参赛者死亡后静默停圈。未确认死亡的离线玩家不会被直接当作死亡。
- **大厅保护**：设置同维度、全高度的圆柱保护区。开局在大厅内或比赛中返回大厅的玩家退出本局统计并免毒，本局不再重新加入；下一局重新记录。
- **个人探测与扫描**：一次性探测器或可重复使用的扫描台揭示下下圈，结果按玩家分别同步，不允许探测第五圈。
- **空降开局**：管理员配置落点、单人或随机双人模式，运输艇载人接近目标后自动从尾部离机，随后由玩家控制滑翔并自然落地。

毒圈支持主世界、下界和末地，并按维度同步相关状态。管理面板和管理指令均由服务端校验管理员权限。

## 快速开始：毒圈比赛

以下指令由具备管理员权限等级 **2** 的玩家执行。

```mcfunction
/give @s poisoncircle:poison_circle_controller
/poisoncircle center
/poisoncircle time 1 60 90
/poisoncircle damage 1 1
/poisoncircle start 500 0
```

这组示例将当前位置设为第一圈中心，设置第一阶段等待 60 秒、缩圈 90 秒，保存基础伤害与逐圈增量，然后以初始半径 500 开始比赛。其余阶段可用 `time 2` 至 `time 5` 分别配置。

也可右键**毒圈控制器**，通过米黄色、棕色边框的面板设置运行、阶段和伤害参数。面板可直接使用当前位置作为中心；输入后需点击应用才会提交服务器。终圈半径只读，停止按钮需要再次点击确认。

- `/poisoncircle start`：使用已保存的初始半径启动；首次默认初始半径为 500。
- `/poisoncircle stop`：结束毒圈，并同时清理正在进行的空降流程。
- 当前运行信息在控制面板与 HUD 中查看；**没有 `/poisoncircle status` 指令**。

| 道具 | 获取指令 | 用途 |
| --- | --- | --- |
| 毒圈控制器 | `/give @s poisoncircle:poison_circle_controller` | 打开毒圈管理面板 |
| 毒圈探测器 | `/give @s poisoncircle:poison_circle_detector` | 右键揭示个人下下圈；也可用 `/poisoncircle detector` 领取 |
| 安全区扫描台 | `/give @s poisoncircle:poison_circle_scanner` | 放置后持续按住右键扫描，不消耗探测器 |

### 探测器与扫描台

**探测器**右键直接揭示下下个安全区，显示中心坐标和半径；成功揭示时消耗一个，创造模式除外。没有可探测圈时不消耗。个人揭示圈在成为当前圈后自动清除。

**扫描台**需先放置。面向扫描台持续按住右键约 **5 秒**，即可揭示同样的下下圈，不消耗探测器，使用次数不限。第五圈不允许揭示。

服务器会先检查扫描台邻接的安全站位，有地面且可站立时才将玩家移至操作位置。扫描自动切换第三人称、锁定移动与瞄准，其他玩家可看到双手操作动作。完成后立即恢复原视角和控制；继续按住不会重复开始，需先松开右键。松开、死亡、切换维度或打开界面会取消扫描。进度由服务器计时，低 TPS 时实际等待可能更长；扫描提示使用声音，不发送聊天消息。

### 可选 Xaero 地图支持

可单独安装对应 **26.3** 的 Xaero 小地图、世界地图，或同时安装两者。当前适配接口为 **Xaero 小地图 26.6.2 / 世界地图 1.47.2**，其所需前置按各自发布页安装。

| 圈线颜色 | 含义 |
| --- | --- |
| 红色 | 当前安全区 |
| 白色 | 下一安全区 |
| 青蓝色 | 该玩家使用探测器或扫描台提前揭示的下下圈 |

个人揭示结果只发送给对应玩家；世界地图切换到其他维度时，不会误画当前维度的毒圈。

## 管理指令

全部 `/poisoncircle` 子指令需要管理员权限等级 **2**。`<参数>` 表示必填，`[参数]` 表示可选；输入时不带尖括号或方括号。

| 指令 | 说明 |
| --- | --- |
| `/poisoncircle center` | 将执行者当前位置设为毒圈中心 |
| `/poisoncircle center <x> <y> <z>` | 使用三个数值坐标设置中心 |
| `/poisoncircle start` | 按已保存的初始半径开始毒圈 |
| `/poisoncircle start <初始半径> 0` | 指定初始半径并开始；初始半径 ≥ 1，最终半径只能为 0，两个数值必须一起填写 |
| `/poisoncircle start airborne` | 按空降管理器中保存的模式与点位启动空降 |
| `/poisoncircle time <阶段> <等待秒数> <缩圈秒数>` | 阶段 1–5；等待 0–86400 秒，缩圈 1–86400 秒 |
| `/poisoncircle damage <基础伤害> [每圈增加伤害]` | 保存伤害设置；数值均 ≥ 0 |
| `/poisoncircle command <阶段> <要执行的指令>` | 设置阶段 1–5 的执行指令 |
| `/poisoncircle detector` | 领取毒圈探测器 |
| `/poisoncircle lobby` | 查看大厅状态，与 `lobby status` 相同 |
| `/poisoncircle lobby status` | 查看大厅状态 |
| `/poisoncircle lobby set <半径>` | 以执行者当前位置设置大厅保护区 |
| `/poisoncircle lobby center <x> <y> <z> <半径>` | 指定坐标及半径设置大厅保护区 |
| `/poisoncircle lobby disable` | 关闭大厅保护 |
| `/poisoncircle stop` | 停止毒圈与空降，并执行相应清理 |

大厅半径范围为 **1–29999984**，大厅中心还受游戏坐标安全范围校验。`center` 的坐标参数为数值，不接受 `~` 或 `^` 写法；使用当前位置时直接省略全部坐标即可。

例如，以当前位置建立半径 30 格的大厅：

```mcfunction
/poisoncircle lobby set 30
/poisoncircle lobby status
```

阶段指令示例：

```mcfunction
/poisoncircle command 1 say 第一阶段指令已执行
```

## 空降模式

空降与毒圈是两个独立的启动入口。**`start airborne` 只启动空降，不会自动开始缩圈**；需要管理员再通过毒圈控制器或 `start` 指令启动毒圈。空降期间玩家免疫毒圈伤害，落地后恢复原毒圈规则。

### 1. 配置落点与分组

领取空降管理器和设置器：

```mcfunction
/give @s poisoncircle:airborne_manager
/give @s poisoncircle:airborne_setter
```

| 设置器操作 | 效果 |
| --- | --- |
| 普通右键地面 | 添加当前工作组的落点，自动取地形高度 |
| 普通左键已有点位 | 删除当前工作组该处点位 |
| 潜行 + 左键 | 打开点位列表，可改名、删除或将管理员本人传送到点位；坐标只读 |
| 潜行 + 右键 | 将当前点位保存为数字命名分组，并切换到空白草稿，继续设置下一组 |

新存档不预建默认组；保存后也不会创建空组。相同点位内容会复用已有组，重复回调不会反复建组。若另有不同的未保存草稿，系统会拒绝覆盖并提示先保存。最多 **8 组、每组 8 点**。

管理员背包里有设置器即可看到同维度 **128 格**内当前组或工作草稿的点位粒子，不必手持；设置反馈只发送给管理员。点位传送仅作用于操作的管理员本人。

### 2. 选择模式与飞行参数

右键空降管理器，选择点位组、单人或多人模式，并在飞行页面设置高度与速度。

- **单人**：一人一架运输艇。
- **多人**：随机两人组队，一队一架；人数为奇数时，最后一人独乘。
- 两种模式共用同一份点位分组；切换模式不清空所选组。
- 每局最多 **32 名生存/冒险玩家**。开局锁定名单与配置。
- 飞行高度默认 **200 格**，接受有限正数；开局仍检查航线地形和游戏坐标安全范围。
- 飞行速度范围 **0.2–2 格/tick**。

### 3. 启动、离机与滑翔

点击管理器的开始按钮，或执行：

```mcfunction
/poisoncircle start airborne
```

1. **倒数 5 秒并登机**：玩家面朝机尾坐在真实座椅位置。运输艇从目标点水平前方 20 格、巡航高度上方 80 格的位置出发，逐步下降至设定高度。
2. **接近目标并自动离机**：登机至少 5 秒后接近并停在目标上空。服务端自动开尾门、起身、沿中央通道移动、走下坡道并解除乘坐。座位距尾门约 5 格，整段开门到离机约 4.2 秒，无需按键或客户端确认。
3. **操控滑翔**：鼠标控制方向和俯仰，**W/S** 调整推进与制动，**A/D** 横移。不需要装备鞘翅，也不绘制鞘翅或生成降落伞。
4. **自然落地**：距下方地形约 50 格切换并腿着陆姿态，近地减速，服务端通过碰撞判断落地。离机与落地均不会把玩家直接传送到地面。

运输艇离机后继续前飞，无人后清理。双人队使用原版计分板队伍，结束清理时恢复原队伍。登机可能跨维度传送；手动中止会将尚在空中的玩家送回开局位置。

## 配置保存

| 内容 | 保存位置 |
| --- | --- |
| 毒圈时间、阶段指令、伤害、半径、各维度中心及大厅设置 | `config/poisoncircle/<存档标识>.json` |
| 控制器本地输入记忆 | `config/poisoncircle-controller.properties` |
| 空降点位、分组与飞行配置 | `<世界存档>/poisoncircle/airborne.json` |

毒圈配置按存档路径隔离，移动存档路径后会使用独立配置。控制器输入记忆不会自动提交，仍需点击应用。空降配置使用原子保存；发现损坏文件时不会静默覆盖。

## 当前版本状态

当前公开包为 **V7 测试版**，已通过 **113 项自动化测试**及目标实例启动、资源加载检查。实际多人操控、披风视觉和帧率尚未完成完整游戏内验证，不作为已验证的性能或兼容性承诺。

- 运输艇引擎循环、尾门打开、玩家离机已有音效，当前三段 Ogg 为**临时原创科幻声音，不是 Apex 原声**。
- 毒圈预警、开始缩圈、受毒反馈已接入音效事件，但尚缺对应原声文件；缺素材的事件保持静默。
- Apex 原声音频替换与人工听音验证尚未完成。当前测试包不会以其他声音冒充官方原声。
